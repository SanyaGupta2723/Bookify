# 📚 Bookifty

**Bookifty** — A modern 📚 online platform to explore 🔍, discover ✨, and buy 🛒 books with a seamless ⚡ and personalized 🎯 reading experience.

---

---

## ✨ Features

* 📖 Browse and explore books
* 🔍 Search & filter by category
* 💰 Sort books by price
* 🛒 Add to Cart functionality
* ❤️ Wishlist support
* ⚡ Buy Now feature
* 📦 Product detail page (with gallery & reviews)
* 🎯 Recommended books section
* 🔐 Secure backend APIs

---

## 🛠 Tech Stack

### Frontend

* ⚛️ React.js
* 🎨 Tailwind CSS
* 🌐 Axios

### Backend

* 🟢 Node.js
* 🚀 Express.js
* 🍃 MongoDB

### Deployment

* ▲ Vercel (Frontend)
* 🔥 Render (Backend)
* ☁️ MongoDB Atlas (Database)

## ⚙️ Installation

### 1️⃣ Clone the repo

```bash
git clone https://github.com/your-username/bookifty.git
cd bookifty
```

---

### 2️⃣ Setup Backend

```bash
cd backend
npm install
npm start
```

Create `.env` file:

```env
PORT=5000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
```

---

### 3️⃣ Setup Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## 🔐 Environment Variables

| Key            | Description               |
| -------------- | ------------------------- |
| MONGO_URI      | MongoDB connection string |
| JWT_SECRET     | Secret key                |
| RESEND_API_KEY | Email service             |
